# `$multi-perspective-skill-synthesis` golden scenarios

These compact scenarios reconstruct observable behavior from the historical Persona Library conversation, issue #11, current repository guidance, and the embedded method in `$persona-skills` and `$persona-panel-orchestration`. The exact historical callable package was not recovered.

## MPSS-1 - distinct perspectives form a reusable core

**Prompt shape:** Compare several named Personas whose workflows expose a possible shared capability.

**Expected behavior:**

- Loads only the named records and relevant evidence, then processes each perspective independently.
- Compares triggers, decisions, actions, outputs, quality signals, constraints, and Tool/recipe needs.
- Separates portable shared judgment from role-specific applications and preserves meaningful disagreement.
- Checks existing Skills, aliases, primitives, relationships, and recipes before proposing a new identity.
- Returns a concrete core profile, evidence/uncertainty, validation plan, and a bounded `$persona-skills` handoff; no live record changes occur without authorization.

## MPSS-2 - reuse or no-new-Skill boundary

**Prompt shape:** The proposed capability is vague, already covered by an existing Skill, or supported by only one materially useful Persona.

**Expected behavior:**

- Narrows the proposal or recommends reuse, a relationship, a Persona application, a workflow method, a recipe, or `$persona-skills` instead of forcing a new Skill.
- Reports the evidence gap and does not invent additional participants or consensus.
- Does not execute Tools, change records, install packages, or imply that a draft was published.
