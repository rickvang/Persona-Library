## Goal

Add an extractable top-level Applications page with a working job application tracker while keeping real application history private and separable from Persona Library.

## Placement review

Mara placement result: create a top-level product surface, not a new canonical primary space and not a new Persona, Skill, Tool, or Playbook.

Closest alternatives rejected:

1. Extend `job-search.html` directly — rejected because that page is a detailed Playbook surface and would couple persistence to orchestration documentation.
2. Extend the seen-job ledger contract — rejected because that contract intentionally covers only repeated-search deduplication.
3. Store application rows in Persona-Library source — rejected because the repository is public and candidate history is private.
4. Build a new standalone repository immediately — deferred; the user wants the surface inside Persona Library now but extractable later.
