# Validation — Candidate Baseline Resume workflow repair

Status: in progress.

## Required checks

- Candidate Baseline Resume is distinct from evidence and reusable Template ownership.
- Standing decisions resolve the exact baseline before role-specific resume composition.
- Missing/unresolved baseline blocks affected composition instead of falling back to secondary profile material.
- Baseline-to-output integrity protects identity/contact, recent employers, chronology, employer/client hierarchy, education, certifications, and candidate-confirmed historical grouping.
- Semantic Resume Content Model mapping cannot silently reconstruct or supersede the active baseline.
- Persona-Library Docs route includes the baseline source-resolution gate.
- Focused validator/test fails when baseline routing or baseline-integrity wording is removed.
- Operating Pack and Persona-Library contracts use compatible precedence and validation language.
- Generated route and Decisions outputs match authored sources.
- No Template-library source or private candidate content is mutated.
