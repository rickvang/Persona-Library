# Archived Work Orders

This directory preserves terminal project packages as read-only historical evidence.

Packages are grouped by the month of their reliable terminal status update:

docs/work-orders/archive/YYYY-MM/<work-order-id>/

Only complete, no-go, and cancelled packages belong here. Active, blocked, draft, and review work remains directly under docs/work-orders/. When merging the final pull request is the last remaining step, move the package in that pull request rather than in a separate archive-only pull request. A later issue may explicitly reopen or correct an archived package; archival never deletes its history.
