# Design context and reference routing — current entry

Status: compatibility entry. [Adaptive UX Design](https://github.com/rickvang/SkillRepo/blob/main/codex/methods/adaptive-ux-design/SKILL.md) owns current design routing; [its architecture/index](https://github.com/rickvang/SkillRepo/blob/main/codex/methods/adaptive-ux-design/ARCHITECTURE.md) maps responsibilities and production routes.

Recover the existing brief, audience/task, north star, content/evidence, artifact and decisions. Load only the method resolving the current gap. Small edits proceed directly; uncertain/substantial work uses a representative concept and user refinement before substantial downstream build.

The small-change lane uses the pull request as the active work record. An existing WorkNode remains in its active Work Graph; this entry does not remove its supervision or create a new graph. Keep one project context, not separate profiles, evidence packets and brief ledgers.

Choose [source references](design-reference-library.md) by the unresolved question. Record what informs the design, why it fits and what does not transfer in the existing brief. Research personas may describe end users when relevant; agent personas are not required.
