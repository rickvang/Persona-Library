# Design coverage — optional aid

Use a compact matrix when the requested scope creates a real risk of losing important user/content/behavior requirements. It is not a prerequisite for [Adaptive UX Design](https://github.com/rickvang/SkillRepo/blob/main/codex/methods/adaptive-ux-design/SKILL.md), a separate brief or proof of experience quality.

| User need / evidence | Content or behavior required | Artifact location | Relevant state/consumer | Check and limitation |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

Link the existing brief and artifact revision. Include only consequential needs and affected uses. Separate observed results from proposed checks; record gaps without inventing coverage. A small edit can use an inline note instead.

Technical coverage complements inspection of comprehension, content and visual/experiential fit; it cannot replace them. Preserve existing project-required acceptance checks.
