# Persona impact matrix

This matrix is a scoped inspection aid. The current Persona record and validator define exact property names and required values. A row identifies likely dependents; evidence must still justify every proposed update.

| Changed input | Inspect in the Persona |
| --- | --- |
| Source or claim | evidence status, confidence, resources, affected context, workflows, activities, questions, revision note |
| Skill or capability | Persona applications, workflow reach, proficiency, quality signals, prerequisites, Tool/recipe links, implications |
| Workflow or activity | tier, trigger, outcome, decisions, handoffs, cadence, collaborators, tools, friction, priorities, success signals, linked Skills |
| Tool requirement or recipe | capability, preferred path, mode, scope, fallback, status, rationale, affected activity/workflow |
| Need, priority, or implication | context, goals, constraints, concerns, evidence, confidence, validation questions |

Classify each inspected dependent as confirms, extends, qualifies, contradicts, invalidates, or unrelated. Do not treat the matrix as an instruction to change every field.
