# Skill formation decision rules

Use these rules to prevent a multi-Persona comparison from turning every overlap into a new Skill.

| Candidate | Choose it when | Do not choose it when |
| --- | --- | --- |
| Existing Skill | Trigger, decisions, outputs, quality, and boundary already fit | Only the name or activity is similar |
| Relationship or application | The portable core exists but the Persona, workflow, or Tool context differs | The new context changes the core judgment itself |
| Primitive | The same portable judgment is a small building block for multiple capabilities | It is only a step in one workflow |
| Composed Skill | A repeatable combination of primitives has its own trigger, output, quality, and boundary | It is a one-off sequence or copied checklist |
| Workflow method | Sequencing, ownership, handoff, or cadence is the reusable part | The reusable value is portable judgment independent of the workflow |
| Tool-use recipe | The durable content is a capability-to-Tool procedure with prerequisites, fallback, and verification | The procedure requires no Tool-specific knowledge |
| New Skill | Multiple distinct perspectives support a concrete, portable capability with observable quality | Evidence is thin, the capability is vague, or an existing identity fits |
| No new Skill | The action is one-off, relational, contextual, or unsupported | A stable reusable core and independent quality signals are demonstrated |

Always preserve the source trail, confidence, unresolved differences, and validation questions behind the choice.
