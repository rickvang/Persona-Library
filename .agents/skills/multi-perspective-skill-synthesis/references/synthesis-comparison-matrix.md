# Synthesis comparison matrix

Use this matrix only after the selected evidence sources or applications have been loaded. Sources may include workflows, project/domain records, existing methods, evaluations, Tool/recipe evidence, or Persona applications when relevant. It is a comparison aid, not a reason to fill missing data by inference.

## How to use it

1. Fill each perspective independently and cite the source or record for material claims.
2. Put a claim in **Shared core** only when at least two materially distinct sources converge on portable judgment, not just the same noun or title.
3. Put context, priorities, protections, and different thresholds in **Context-specific application** unless evidence proves they are universal.
4. Put conflicts and absent evidence in a separate unresolved list; do not resolve them by averaging.
5. Use the final column to distinguish observed, documented, inferred, proposed, and unknown claims.
6. Do not require Persona records or a panel. Persona applications are one optional source type; synthesis is valid when distinct non-Persona evidence satisfies the same comparison contract.

The matrix should produce a decision about the smallest stable artifact: existing Skill, relationship, primitive, composed Skill, application, workflow method, Tool-use recipe, or no new Skill.
