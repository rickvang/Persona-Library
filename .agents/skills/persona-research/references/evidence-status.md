# Evidence and source status

## Claim status

- **Observed:** directly supported by a named source, an existing record, or an explicitly reported behavior. Preserve the source scope and wording limits.
- **Synthesis:** a reasoned pattern derived from multiple observations or connected records. Name the supporting evidence and the inference.
- **Hypothesis:** plausible but unverified. State what would validate or falsify it.
- **Unknown:** the available material does not establish the claim. Do not fill the gap with a plausible detail.

Confidence is a judgment about support, not a substitute for a source. Explain why confidence is high, medium, low, or otherwise represented by the current record contract. Do not silently convert confidence into certainty.

## Source metadata

For each material source, preserve publisher or author, title or description, URL or stable locator, date checked, publication date when known, population/context, contribution, and limitation. If a value is unavailable, record it as unknown or omit it according to the current repository schema; never invent it.

## New-source classification

Compare a new source with the affected existing claims:

- **Confirms:** supports an existing claim without changing its scope.
- **Extends:** adds supported context, behavior, workflow, or population.
- **Qualifies:** narrows, dates, conditions, or lowers confidence in a claim.
- **Contradicts:** conflicts with a claim; preserve the conflict and open a question.

One source can have different classifications for different claims. Update only the affected claims and resource trail. The classification is evidence for a reconciliation review, not an instruction to perform unrelated edits.
