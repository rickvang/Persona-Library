# Tool status and evidence

- **Observed:** directly supported by a named execution record or in-scope source.
- **Reported:** supplied but not independently verified in the current runtime.
- **Proposed:** awaiting review or authorization.
- **Reviewed or validated:** accepted through the repository process with evidence and scope.
- **Unknown:** not established by available material.

A single usage note remains a record of one attempt. It is not automatically a reviewed lesson, Tool-use recipe, or validated shared guidance. Preserve failures, limitations, source scope, and confidence.
