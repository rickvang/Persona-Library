# Tool record contract

The current Tool record and validator define exact property names and required values. The maintenance workflow should keep these concepts separate when they are known: identity and aliases, capability, connector path, workspace, scope, data sensitivity, risk, permission, approval, verification, fallback, availability, evidence, relationships, recipes, lessons, and revision history.

A catalog record describes what a Tool can be or what a reviewed usage established. It does not prove that a connector, credential, workspace, permission, or approval is configured. Actual runtime checks belong to Tool discovery and safe execution.
