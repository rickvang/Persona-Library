# Tool relationship rules

Relate Tools explicitly to Personas, Skills, Playbooks, Tool-use recipes, capabilities, resources, workflows, or replacements. A Persona requirement expresses a capability need; a recipe expresses a reviewed procedure; a usage note records one attempt. None of these alone proves current availability or permission.

Before merging or superseding records, compare stable identity, capability, scope, workspace, risk, evidence, and revision history. If the records differ materially, preserve both or recommend supersession rather than silently collapsing them. Broken or ambiguous relationships must be reported.
