# Usage record and lesson status

- **Usage note:** one observed attempt, including Tool, action, target/workspace, mode, approval, result, evidence, failure/friction, and limitations.
- **Candidate lesson:** a possible reusable learning awaiting review or repeated evidence.
- **Reviewed lesson:** accepted through the repository review process with defined scope and evidence.
- **Tool-use recipe:** a reviewed capability-to-Tool procedure with prerequisites, mode, fallback, and verification.
- **Validated guidance:** repeated or explicitly reviewed evidence safe to share as general guidance.

Never promote a usage note automatically. Keep failed attempts and unknowns visible. Send durable records, lessons, recipes, or artifacts through the universal `$change-impact-reconciliation` protocol once after the execution workflow; send canonical Tool-record changes to `tool-record-maintenance`.
