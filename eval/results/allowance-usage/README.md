# Allowance-usage evidence

This directory may contain sanitized, explicitly authorized subscription allowance observations that conform to `eval/allowance-usage.md`.

Do not commit raw screenshots, account identifiers, credentials, private conversation content, full `/status` transcripts with unrelated private data, or fabricated examples presented as observations. A real observation should preserve only the product-exposed allowance values, provenance, task metadata required for attribution, and named caveats.

No paid API request is required to populate this directory.
